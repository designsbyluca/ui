# ScrollFillText

A large centred paragraph whose words fill from `ink-unread` to `foreground` as you scroll.

**Pro**

Two to four short sentences at `headline` size (30px on mobile). `tail` fills the last words in `ink-display-muted`. Once per page, as a bridge after the hero. Screen readers get the whole sentence.

**Motion:** only the colour changes, word by word. Filled at once with reduced motion.
