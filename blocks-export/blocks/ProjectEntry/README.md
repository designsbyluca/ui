# ProjectEntry

A portfolio entry: a 16:9 image or video, a sentence in `lead` size and a link.

**Pro**

- `secondary` aligns it right with the text in `ink-display-muted`, for alternating rhythm.
- `thumb` turns the link into a case link with a small square thumbnail in a fine frame; `onPlay` opens a CaseStory.
- `comingSoon` shows a "Coming soon" chip on the image.

**Motion:** the image zooms to `zoom-media` on hover over `dur-reveal`.
