# FeatureTiles

Services or features as square tiles joined in one grid with 1px hairline gaps.

**Pro**

- Each tile has a serif-capital number (01, 02 …) at the top and a title with one sentence at the bottom.
- `tone`: `inverse` (near-black, at most one per row), `stone` (`surface-200`); default `muted`.
- `columns` sets the count (default 4; 2 below 900px, 1 below 520px).
