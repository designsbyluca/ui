# TestimonialRail

A slow rail of quote cards and photos that pauses on hover and focus.

**Pro**

Quote cards: `muted`, square, 448 × 344, quote in `quote`, initials in a dark circle, name and role in serif capitals, role in `muted-foreground`. Photo cards are the same size. `rows` runs two rows in opposite directions. Only real testimonials, with consent.

**Motion:** one pass takes `dur-marquee` (80s). Stands still and scrolls sideways with reduced motion.
