# Wordmark

One word set very large: the name as a hero or as a close above the footer.

**Pro**

- `size="hero"` (default): `display-wordmark` as `h1` with a `tagline` on its baseline. Replaces the Hero.
- `size="footer"`: right-aligned, fitted to the width (font up to 480px).
- `echo` repeats the first letter in front (footer only); works with clear shapes such as A, M, V.
- Below 760px: 120px with the tagline underneath.

For short names, up to about 8 characters.
