# NavBar

The header: name on the left, two to four links in the middle, a link and a default button on the right.

**Pro**

- On white: text in `foreground`.
- `overMedia`: over a hero photo, white text on a dark scrim.
- `sticky`: sticks to the top; with `overMedia` it turns solid after `solidAfter` px.
- `floating`: a square off-white bar with a hairline and a soft shadow, 12px below the top. `secondary` becomes an outline button; `lang` adds a language switch; `menu: true` on a link adds a +.

Mobile needs its own menu; the page provides it.
