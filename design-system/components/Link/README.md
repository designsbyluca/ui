# Link

A text link with a 1px line below that thickens to 2px on hover.

**Free** · shadcn/ui-compatible: same name, props and variants.

`arrow` adds → for "continue", `external` adds ↗ and opens a new tab, `variant="muted"` for footer and legal links (line only on hover). Focus shows the ochre ring; `aria-disabled="true"` turns the line dashed. Use Button for actions, Link for navigation.
