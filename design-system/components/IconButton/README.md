# IconButton

A 48px square button with a single line icon.

**Free** · shadcn/ui-compatible: same name, props and variants. In shadcn/ui this is `Button size="icon"`; IconButton defaults to the `outline` variant.

Always pass `aria-label` – it is the only name a screen reader gets. Variants as Button; sizes `icon` (48px) and `sm` (44px). Use 18px icons with a 1.25px square-capped stroke.
