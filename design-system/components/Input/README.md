# Input

A text field with lots of room and a single line below: 56px high, 19px text, no box.

**Free** · shadcn/ui-compatible: same name, props and variants.

States: hover darkens the line, focus turns it into a 2px ochre line, `disabled` makes it dashed with muted text, `aria-invalid="true"` turns it red (point `aria-describedby` at the error). `variant="boxed"` (extension) draws a very fine frame for dense forms. All native input props pass through.
