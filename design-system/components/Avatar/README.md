# Avatar

A picture of a person, with initials as fallback – the one round element in the system.

**Free** · shadcn/ui-compatible: same name, props and variants. `Avatar` › `AvatarImage` + `AvatarFallback` as in shadcn/ui.

Sizes `sm` 32px, default 44px, `lg` 64px. The fallback shows while the image loads and when it fails. Give the image an `alt` that names the person.
