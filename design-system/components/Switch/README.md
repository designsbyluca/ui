# Switch

An on/off toggle for settings that apply at once: a 44 × 24px rectangle with a square thumb.

**Free** · shadcn/ui-compatible: same name, props and variants.

`checked` / `defaultChecked` / `onCheckedChange`. Off: quiet track, muted thumb on the left. On: near-black track, off-white thumb on the right. States: focus ring, disabled (dashed), `aria-invalid="true"`.
