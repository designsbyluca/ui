# Alert

A message in the page flow: the square, a title and one or two sentences, on a quiet surface.

**Free** · shadcn/ui-compatible: same name, props and variants. `Alert` › `AlertTitle` + `AlertDescription`.

- `default` – `muted` surface, ochre square, `role="status"`.
- `destructive` – `red-tint` surface, red square, `role="alert"`.

Pass `icon` to replace the square with an 18px line icon. For messages that come and go, use Toast.
