# Tooltip

A short hint on hover or keyboard focus.

**Free** · shadcn/ui-compatible: same name, props and variants. `TooltipProvider` › `Tooltip` › `TooltipTrigger` + `TooltipContent`.

Opens after `delayDuration` (500ms) on hover, at once on focus; Escape closes it. `side`: top, right, bottom, left. A square near-black box with off-white text. One short sentence, no links inside.
