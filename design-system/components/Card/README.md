# Card

Groups related content – as a quiet surface without border or shadow, or editorially with the image above and the text below.

**Free** · shadcn/ui-compatible: same name, props and variants. `Card` › `CardHeader` (`CardTitle`, `CardDescription`, `CardAction`), `CardContent`, `CardFooter`; extensions `CardMedia` and `CardMeta`.

- `variant="default"` – `card` fill, 40px padding, square.
- `variant="editorial"` – no surface: `CardMedia` (4:3 image), a serif-capital `CardMeta` line, a 28px title, muted text, a link button. The image brings the colour.
- `variant="outline"` – a fine frame instead of the fill.
