# Badge

A small square label in capitals: a fine line and, for the one that matters, the ochre square.

**Free** · shadcn/ui-compatible: same name, props and variants. `Tag` is the same component under its old name.

Variants: `default` (line + ochre square), `secondary` (quiet fill), `outline` (line only), `destructive` (red line and square), and the extension `inverse` (near-black fill). 28px high, 11.5px capitals with +8 % tracking. Not interactive; `asChild` wraps a link.
