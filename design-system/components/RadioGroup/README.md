# RadioGroup

One choice from a few visible options: a circle with a dot.

**Free** · shadcn/ui-compatible: same name, props and variants. `RadioGroup` › `RadioGroupItem` as in shadcn/ui.

`value` / `defaultValue` / `onValueChange`, `disabled`, `orientation`. Arrow keys move the selection inside the group. Radios are round on purpose – next to the square checkboxes, the circle says “pick one”. Error: `aria-invalid="true"` on the group. Name the group with `aria-label` or `aria-labelledby`.
