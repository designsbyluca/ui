# Label

The name of a form control, linked with `htmlFor`.

**Free** · shadcn/ui-compatible: same name, props and variants.

Above inputs: 13px in `muted-foreground` (`sg-field` stacks label, control and hint). Beside checkboxes, radios and switches: 15px in `foreground` (`sg-option-row`). Hints use `sg-field-hint`; errors `sg-field-error` with the red square.
