# Checkbox

A 20px square for yes/no choices; checked fills near-black with a check.

**Free** · shadcn/ui-compatible: same name, props and variants.

`checked` / `defaultChecked` / `onCheckedChange`; `checked="indeterminate"` shows a dash. States: hover, focus (ochre ring), disabled (dashed line), `aria-invalid="true"` (red line). Always pair with a `Label`.
